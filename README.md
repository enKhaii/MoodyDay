--- HOW TO COMMIT ---<br>
Open Terminal on Bottom-Left corner<br>
Type the commands below step by step<br><br>

git add .                       # stage all changes (or git add <filename> for specific files)<br>
git commit -m "YOUR MESSAGE"<br>
git push origin dev             # or whichever branch you're on<br>
